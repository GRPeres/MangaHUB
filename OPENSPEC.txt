OpenSpec: MangaHub

Version: 0.2
Status: Draft
Owner: Self-hosted personal project
Deployment Target: TrueNAS SCALE (Docker containers)
Primary Stack: .NET 9 / ASP.NET Core

1. Project Overview

MangaHub is a self-hosted manga reading platform that provides:

- User authentication
- Persistent reading progress
- Unified manga library
- Local manga storage
- Remote manga source integration
- Responsive web reader
- Metadata aggregation
- Future support for books and comics

The system should present local and remote manga as a single library to the user.

2. Goals

Primary Goals

- Host manga on TrueNAS
- Read manga through a browser
- Track reading progress per user
- Resume reading automatically
- Support local manga archives
- Support remote manga providers
- Search across all sources
- Provide easy Docker deployment
- Keep the codebase maintainable and expandable

Secondary Goals

- Metadata enrichment
- Series following
- Automatic chapter updates
- Mobile-friendly reader
- OPDS support
- Multi-user support

3. Non-Goals

Not required for MVP:

- Native mobile apps
- Offline downloads
- Social features
- Comments
- Ratings
- Recommendations
- DRM support

7. Local Source Specification

Supported Formats

Required:

- CBZ

Future:

- ZIP
- CBR
- PDF
- EPUB

Directory Layout

library/

- One Piece/
  - Chapter 0001.cbz
  - Chapter 0002.cbz
- Dandadan/
  - Chapter 0001.cbz

Scanner Behavior

The scanner must:

- Detect new series
- Detect deleted series
- Detect new chapters
- Detect deleted chapters
- Calculate file hashes
- Count pages in CBZ archives
- Store metadata in PostgreSQL
- Never trust user-provided paths
- Prevent path traversal when serving archive pages

Scan frequency:

- Every 1 hour

Suggested .NET Components

- ILocalLibraryScanner
- IArchiveReader
- LocalLibraryScanHostedService

8. Remote Source Specification

Source Interface

Every source connector must implement a common abstraction:

```csharp
public interface IMangaSource
{
    string Name { get; }
    Task<IReadOnlyList<MangaSearchResult>> SearchAsync(string query, CancellationToken cancellationToken);
    Task<MangaSeries?> GetSeriesAsync(string id, CancellationToken cancellationToken);
    Task<IReadOnlyList<MangaChapter>> GetChaptersAsync(string seriesId, CancellationToken cancellationToken);
    Task<IReadOnlyList<MangaPage>> GetPagesAsync(string chapterId, CancellationToken cancellationToken);
}
```

Required Sources

MangaDex

Capabilities:

- Search
- Metadata
- Chapters
- Page retrieval

Future Sources

- Plugin-based architecture
- Additional source assemblies registered through dependency injection

Example:

```csharp
public sealed class MangaDexSource : IMangaSource
{
    public string Name => "mangadex";
}
```

11. Authentication

MVP

- Local accounts
- Password hashing with Argon2id
- JWT session stored in HttpOnly cookie

Endpoints:

- POST /auth/register
- POST /auth/login
- POST /auth/logout
- GET /auth/me

Session Rules

- Access token is a JWT
- Token is stored in an HttpOnly cookie
- Refresh token support can be added after MVP
- Login endpoint must be rate-limited

15. Background Jobs

Library Scan

Schedule:

- Every hour

Responsibilities:

- Scan files
- Update database
- Generate metadata
- Remove missing chapters and series

Remote Sync

Schedule:

- Every 6 hours

Responsibilities:

- Update followed series
- Fetch new chapters
- Refresh metadata

Suggested Implementation

- BackgroundService
- PeriodicTimer
- Scoped services created through IServiceScopeFactory

16. Security Requirements

Must:

- Hash passwords with Argon2id
- Rate-limit login
- Validate uploaded and mounted paths
- Prevent path traversal
- Sanitize metadata
- Restrict served files to the configured library root
- Keep JWT signing secrets outside source control
- Use HTTPS in production

17. Deployment

Docker Compose Services

- web
- api
- postgres
- redis optional for future queues/cache

Environment Variables

- DATABASE_URL=
- JWT_SECRET=
- LIBRARY_PATH=
- MANGADEX_ENABLED=true
- ASPNETCORE_ENVIRONMENT=Production

TrueNAS Notes

- Mount the manga dataset into the api container as read-only when possible.
- Keep PostgreSQL data on a persistent dataset.
- Keep secrets in TrueNAS app configuration or environment variables, not in Git.

18. MVP Definition

A release is considered MVP-complete when:

- User can register
- User can login
- User can browse local library
- User can read CBZ files
- Reading progress persists
- User can search MangaDex
- User can read MangaDex chapters
- Continue Reading works
- Library scanner works
- Docker deployment works
